Проблема

Китайский — сложнейший
язык в мире

❌ Почему большинство бросают
Репетитор раз в неделю — слишком редко. Между уроками ученик не практикуется
и к следующему занятию забывает всё. Прогресс не виден ни учителю, ни ученику.
Мотивация падает — человек сдаётся через 2–4 недели.
✅ Наш подход
5–20 минут каждый день прямо в Telegram — без скачиваний и регистраций.
Бот напоминает, хвалит, ведёт счёт стриков. Учитель видит, кто занимается,
а кто пропускает — и знает, что разобрать на занятии.

Как работает

2️⃣
Мини-урок «aha moment»
3 простых вопроса сразу после регистрации — ученик понимает «я уже кое-что знаю!». Конфетти, XP, мотивация.
Работает
3️⃣
Дашборд и разделы
Основы / Разговорный / Грамматика / Деловой. Уроки открываются последовательно. Первые 3 дня — бесплатно.
Работает
4️⃣
Упражнение → Итог → Дашборд
10 заданий в уроке, прогресс-бар, кнопка «Не знаю» без штрафа. Итог: XP + выученные слова с произношением.

Технологии

Что под
капотом

  • Vanilla JS + HTML + CSS — без фреймворков, бандл <100KB
  • Telegram Web App SDK — нативная тема, BackButton, CloudStorage
  • Noto Sans SC — шрифт для иероглифов
  • Web Speech API — голосовое произношение
  • Node.js + aiogram — Telegram-бот @KitaiskuiBot
  • PM2 — автозапуск бота 24/7
  • Claude API — AI-наставник (планируется)
  • Vercel — хостинг с авто-деплоем
